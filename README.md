## Setup

Install dependencies and build site:

```sh
# Get ruby
apt-get install ruby-full
gem install bundler jekyll

# Clone repo
git clone git@github.com/cjtu/cjtu.github.io

# Install dependencies
cd cjtu.github.io
bundle install
bundle exec jekyll serve --no-watch
```
